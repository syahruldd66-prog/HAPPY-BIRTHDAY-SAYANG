ULTAH CINEMATIC PINK

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html.
3. Foto sudah ada di assets/images/.

Struktur:
- index.html = halaman utama
- css/main.css = desain utama
- css/animations.css = animasi
- css/mobile.css = tampilan HP
- js/particles.js = bintang & hati
- js/main.js = interaksi, surat, lilin, confetti, fireworks, musik
- assets/images/ = 6 foto yang kamu kirim

Catatan:
Musik dibuat dengan Web Audio API, jadi tidak ada MP3 eksternal.
